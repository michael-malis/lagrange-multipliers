# Множители Лагранжа

Одна интерактивная русскоязычная статья о геометрии условного экстремума. Три сцены: поверхность и ограничение, касательная компонента градиента, несколько экстремумов на окружности.

[Открыть сайт](https://michael-malis.github.io/lagrange-multipliers/) · фактические результаты проверки — `docs/PROGRESS.md` и `docs/QA.md`.

## Разработка

Node.js 22.12+ (CI: Node 24), npm.

```sh
npm ci
npm run dev
npm test
npx playwright install chromium
npm run build
npm run test:browser
```

Сборка создаёт только `dist/index.html`. Откройте его двойным щелчком: сеть и локальный сервер не нужны. JavaScript, CSS и шрифты KaTeX включены в HTML. При отсутствии WebGL доступны резервные SVG, формулы и управление профилем.

Оформление — тёмная академическая статья: строгая типографика, тонкие разделители, семантические цвета графиков. Версия 2.0 начинает с задачи на параболоиде и непосредственной подстановки. Затем параметризация связывает допустимую прямую, 3D-поверхность и график высоты; через цепное правило и исчезновение касательной проекции выводится условие Лагранжа. Третья сцена классифицирует четыре точки окружности и показывает отдельный пример, где условие выполняется при ненулевом градиенте, но экстремума нет. Между 3D и 2D можно переходить, не теряя выбранную математическую точку. Есть переключатель «Демонстрация», клавиатурная навигация и две необязательные проверки понимания.

## Публикация и проверка

Push в `main` запускает `.github/workflows/deploy.yml`: установка, математические тесты, сборка, браузерная проверка offline-файла, GitHub Pages и проверка публичной версии. Источник Pages — GitHub Actions. `dist/` не хранится в Git.

```sh
npm run test:public
```

Проверка публичного сайта сверяет SHA с локальным HEAD (в CI — `EXPECTED_SHA`), выполняет действия во всех трёх сценах, проверяет сброс, шрифты, консоль и сеть. Скриншоты и traces находятся в `test-results/`; CI сохраняет их в артефакте `browser-evidence-<SHA>` на 14 дней. Лицензионные уведомления Three.js и KaTeX встроены в HTML-комментарий сборки.

`docs/UPGRADE_SPEC.md` — актуальная утверждённая спецификация v2.0; `TASKS.md` — критерии и текущий прогресс шестефазной разработки. `docs/SPEC.md` — сохранённая историческая спецификация v1.1; `CODEX_MASTER_PROMPT.md` — исторические инструкции, применимые лишь постольку, поскольку не противоречат v2.0; `docs/PROGRESS.md` — фактические результаты; `docs/ACCEPTANCE.md` — приёмка. Сценарий в `docs/RUN_OF_SHOW.md` рассчитан на 18 минут плюс 2 минуты резерва. Человеческая проверка времени и понимания пройдена 2026-11-03.

## Управление реализацией v2.0

Задачи и верифицируемые критерии собраны в [`TASKS.md`](TASKS.md). Отметки `[x]` ставятся только при выполнении критерия, а незакрытые задачи не следует интерпретировать как готовые функции. Публикацию проверяет workflow, который сначала тестирует автономный `file://`, затем проверяет **тот же SHA** на GitHub Pages.
