# Множители Лагранжа

Один автономный интерактивный математический учебник на **русском и английском языках** (RU/EN) о методе множителей Лагранжа. Три связанные сцены: допустимое движение на поверхности, геометрический вывод условия через касательную проекцию градиента, классификация стационарных точек на окружности и контрпример без экстремума.

[Открыть сайт](https://michael-malis.github.io/lagrange-multipliers/) · фактические результаты проверки — `docs/PROGRESS.md` и `docs/QA.md`.

## Разработка

Node.js 22.12+ (CI: Node 24), npm.

```sh
npm ci
npm run dev
npm test
npx playwright install chromium
npm run build
npm run test:browser
```

Сборка создаёт только `dist/index.html`. Откройте его двойным щелчком: сеть и локальный сервер не нужны. JavaScript, CSS и шрифты KaTeX включены в HTML. При отсутствии WebGL доступны резервные SVG, формулы и управление профилем.

Оформление — тёмная академическая статья: строгая типографика, тонкие разделители, семантические цвета графиков. Версия 2.0 начинает с задачи на параболоиде и непосредственной подстановки. Затем параметризация связывает допустимую прямую, 3D-поверхность и график высоты; через цепное правило и исчезновение касательной проекции выводится условие Лагранжа. Третья сцена классифицирует четыре точки окружности и показывает отдельный пример, где условие выполняется при ненулевом градиенте, но экстремума нет. Для этого случая профиль автоматически увеличивает область вокруг стационарной точки перегиба; кнопка возвращает всю окружность. В 3D показан гладкий сплошной диск настоящей поверхности вокруг окружности. Решение выбрано после сравнения трёх вариантов; критерии и реальные скриншоты описаны в [аудите вариантов](docs/VISUAL_VARIANTS_AUDIT.md). Между 3D и 2D можно переходить, не теряя выбранную математическую точку. Есть переключатель «Демонстрация», клавиатурная навигация.

## Языки и навигация

В компактной шапке расположены выпадающее меню трёх демонстраций и переключатель **RU / EN**. Изменение языка происходит без перезагрузки и не сбрасывает параметры математических моделей, камеру, положение точки, этап доказательства или выбранную функцию. Выбор языка сохраняется в `localStorage` между посещениями на GitHub Pages. Английский текст, подписи SVG, элементы управления, динамические объяснения и доступные названия используют общий каталог `src/i18n/catalog.js`; математические обозначения остаются теми же. Десятичные подписи: в RU — запятая, в EN — точка.

Основные преобразования контрпримера даны отдельными выровненными KaTeX-блоками. На узких экранах геометрия и профиль переключаются без создания дублирующих сцен. В демонстрационном режиме доступно то же меню сцен и RU/EN.

Матрица требований и фактических подтверждений: [приёмка RU/EN и UX/UI](docs/FINAL_BILINGUAL_ACCEPTANCE.md), [профессиональный UX-аудит](docs/UX_UI_AUDIT_V21.md). Финально проверенная функциональная версия: [GitHub Actions run 41765652750](https://github.com/michael-malis/lagrange-multipliers/actions/runs/41765652750): 43/43 браузерных сценария, автономные Firefox и WebKit, публичная проверка точного SHA и сохранения языка после перезагрузки.

## Публикация и проверка

Push в `main` запускает `.github/workflows/deploy.yml`: установка, математические тесты, сборка, браузерная проверка offline-файла, GitHub Pages и проверка публичной версии. Источник Pages — GitHub Actions. `dist/` не хранится в Git.

```sh
npm run test:public
```

Проверка публичного сайта сверяет SHA с локальным HEAD (в CI — `EXPECTED_SHA`), выполняет действия во всех трёх сценах, проверяет сброс, шрифты, консоль и сеть. Скриншоты и traces находятся в `test-results/`; CI сохраняет их в артефакте `browser-evidence-<SHA>` на 14 дней. Лицензионные уведомления Three.js и KaTeX встроены в HTML-комментарий сборки.

`docs/UPGRADE_SPEC.md` — актуальная утверждённая спецификация v2.0; `TASKS.md` — критерии и текущий прогресс шестефазной разработки. `docs/SPEC.md` — сохранённая историческая спецификация v1.1; `CODEX_MASTER_PROMPT.md` — исторические инструкции, применимые лишь постольку, поскольку не противоречат v2.0; `docs/PROGRESS.md` — фактические результаты; `docs/ACCEPTANCE.md` — приёмка. Сценарий в `docs/RUN_OF_SHOW.md` рассчитан на 18 минут плюс 2 минуты резерва. Человеческая проверка времени и понимания пройдена 2026-11-03.

## Управление реализацией v2.0

Задачи и верифицируемые критерии собраны в [`TASKS.md`](TASKS.md). Отметки `[x]` ставятся только при выполнении критерия, а незакрытые задачи не следует интерпретировать как готовые функции. Публикацию проверяет workflow, который сначала тестирует автономный `file://`, затем проверяет **тот же SHA** на GitHub Pages.
