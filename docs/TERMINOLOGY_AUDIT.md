## Принятые термины

| Прежнее выражение | Принятый вариант | Причина |
| --- | --- | --- |
| «Экстремум на подмножестве» | «Экстремум при ограничении» / «условный экстремум» | Общепринятая формулировка задачи с уравнением ограничения |
| «Допустимая траектория» | «Допустимая прямая» или «допустимая кривая» | Ограничение задаёт геометрическое множество; «траектория» неоправданно подчёркивает динамику |
| «Пространственная траектория» | «Пространственная кривая» | Речь о графике параметризации \(\Gamma(t)\) |
| «Равенство нормалей» | «Коллинеарность градиентов» | Градиенты могут быть противоположно направлены, а при \(\lambda=0\) градиент цели может быть нулевым |
| «Точка на общей нормали» (в вычислениях) | «Выразим координаты через множитель Лагранжа» | В исходном контексте неизвестные определяются непосредственно из уравнений, а не из построенной нормальной прямой |
| «Касательная» при обозначении \(T\) | «Касательный вектор» | Не смешивать касательную прямую с её направляющим вектором |
| «Нормаль» при обозначении \(\nabla g\) | «Градиент ограничения» | Точная природа объекта; при \(\nabla g\ne0\) он нормален линии уровня \(g=c\) |
| «Проекция \(\nabla f\) на \(T\)» | «Ортогональная проекция градиента на прямую, порождённую \(T\)» | Вектор проецируют на одномерное подпространство, а не на отдельный вектор |
| «Знаковый коэффициент» | «Коэффициент при \(T\)» | Подчёркивает скаляр в разложении \(\operatorname{proj}_T\nabla f=(h'/2)T\), не путая его с неотрицательной нормой |
| «Плоская проекция» (рисунок 3) | «Положение точки на окружности» | В конкретном блоке отображается допустимая точка в координатах \(x,y\), а не отдельный оператор проектирования |
| «Контрпример» без контекста | «Другая целевая функция \(f_{\mathrm{alt}}(x,y)=x^2+y^2-1+y^3\) на той же окружности» | Это замена функции, а не изменение ограничения |
| «Кандидаты» на графике без пояснения | «Стационарные точки» | Точно обозначает решения \(h'(t)=0\); классификация проводится отдельно |

## Разграничения, которые необходимо сохранять

- **Стационарная точка:** при гладкой параметризации и регулярном движении \(h'(t_0)=0\); максимум или минимум отсюда автоматически не следует.
- **Критическая точка** в более широком смысле иногда включает точки, где производная не существует; для гладких функций рассматриваемых примеров используется более узкий термин «стационарная».
- **Градиент \(\nabla f\)** — вектор в плоскости аргументов \(xy\). Касательные к координатным сечениям 3D-поверхности — другие векторы.
- **Производная вдоль параметра:** \(h'(t)=\nabla f(r(t))\cdot r'(t)\). **Производная по направлению единичного вектора** \(\widehat T\) равна \(D_{\widehat T}f=h'(t)/\|T\|\); эти величины не совпадают при \(\|T\|\ne1\).
- **Проекция на касательную прямую** — вектор, который может менять направление; её **норма** неотрицательна.
- **Необходимое условие Лагранжа** при регулярном ограничении — \(\nabla f=\lambda\nabla g\); оно не классифицирует экстремум и не гарантирует его наличие.
- **Лагранжиан:** \(\mathcal L=f-\lambda(g-c)\). Равенство нулю частных производных лагранжиана по \(x,y,\lambda\) эквивалентно соответствующей системе уравнений Лагранжа.

## Принцип оформления

Названия геометрических этапов выводятся из одного источника (данных текста доказательства), а не дублируются вручную в интерфейсе. Обозначения \(h\), \(h'\), \(T\), \(\nabla f\), \(\nabla g\) и \(\lambda\) сохраняют единую семантику во всех сценах.

Этот файл отражает редакционный аудит отображаемых пользователю текстов и названий. Технические документы, которые описывают устаревшие этапы проектирования, остаются историческими записями и не являются текущими интерфейсными подписями.

## Обновление для спецификации v2.0

- **Уровень целевой функции**: `f(x,y)=ℓ`, `ℓ=h(t)=f(P)`; не употреблять `c` для высоты.
- **Уравнение ограничения**: `g(x,y)=c`, где для прямой `c=3`, для окружности `c=1`.
- **Подстановка и параметризация**: исключение `y=3−x` — частный случай параметризации `r(t)=(t,3−t)`; параметризация перечисляет допустимые точки, но не обязательна в общем методе Лагранжа.
- **Касательный вектор** `T=r′(t)` лежит в плоскости аргументов. Вектор касательной к пространственной кривой `Γ(t)` имеет третью компоненту `h′(t)`; эти объекты не тождественны.
- **Производная по параметру** `h′(t)=∇f·T` и **производная по единичному направлению** `D_{T̂}f=h′(t)/‖T‖` — различные величины.
- **Ортогональная проекция** — вектор; коэффициент при T может иметь любой знак; норма проекции всегда неотрицательна.
- **Регулярная стационарная точка** удовлетворяет необходимому условию, но экстремум не гарантирует. Сильный контрпример на окружности имеет ненулевой `∇f` и `λ=1` при отсутствии экстремума.
- **Локальный и глобальный максимум** на окружности различны: высоты 0 и 2. Компактность гарантирует наличие глобальных экстремумов, но не классифицирует кандидатов.
