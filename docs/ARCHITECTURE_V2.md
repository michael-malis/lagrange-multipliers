# Архитектура и карта приёмки v2.0

Документ составлен по проверенным исходным файлам ветки `main`, утверждённой `docs/UPGRADE_SPEC.md`, существующей инфраструктуре и `TASKS.md`. Не заменяет результаты реальных браузерных тестов.

## Инвентаризация

| Слой | Файлы | Ответственность / проверяемый инвариант |
| --- | --- | --- |
| Учебный маршрут | `src/content/lesson.js`, `proof.js`, `application.js` | A → B → C → D → E → F → G; ни формула Лагранжа, ни лагранжиан не опережают мотивировку |
| Математика | `src/math/core.js`, `examples/{paraboloid,cylinder,counterexample,distance}.js` | Независимые от 3D расчёты `f,g,r,h,dh,gradient,normal,tangent,lambda` |
| Единая точка первых двух сцен | `src/state/paraboloidStore.js`, `sceneStore.js` | Один параметр `t`, состояние шага доказательства отдельно от ракурсов |
| Геометрия | `src/scenes/{Surface,Gradient,Cylinder}Scene.js`, `src/graphics/{svg,three}/` | 3D-поверхности, 2D-уровни, профили; камеры не изменяют модель |
| Режимы | `src/ui/demo.js`, `mobileViews.js`, `format.js`, `styles.css` | Читать/Демонстрация, клавиатура, мобильная геометрия/профиль, KaTeX |
| Публикация | `vite.config.js`, `scripts/{audit-build,license-notices,verify-public}.mjs`, `.github/workflows/deploy.yml` | Один автономный `dist/index.html`, CI, Pages по исходному URL |
| Верификация | `tests/math/`, `tests/interactions/`, `docs/QA.md` | Математика, offline, pan/zoom, разные viewport, реальная публикация |

## Переходы и сохранение состояния

| Действие | Сохраняется | Меняется |
| --- | --- | --- |
| 3D → 2D → 3D | `t`, `P=r(t)`, `h`, `h'`, активный этап | Локальная композиция/камера |
| Ползунок/перетаскивание любой из двух первых сцен | Шаг доказательства, ракурс | Общая `t`, все значения модели |
| Pan/zoom/reset-view графика | `t`, `h`, `h'` и 3D-камера | Только окно SVG-камеры |
| Далее/Назад | `t`, камеры | Показанный этап и пояснение |
| Читать ↔ Демонстрация | `t`, шаг, выбранная функция | Раскладка и видимые элементы |
| Мобильная Геометрия ↔ Профиль | Математическое состояние | Видимый блок сцены |
| Смена модели третьей сцены | Окружность `g=x²+y²=1` | Целевая функция, `t` на новом начальном значении, вычисления/векторы |

## Обязательные ограничения

- Репозиторий остаётся `michael-malis/lagrange-multipliers`, ветка `main`; исторический `docs/SPEC.md` сохранён.
- Обязательных CDN и внешних API нет; Vite собирает единый HTML, KaTeX/Three.js должны быть встроены.
- CI: `npm ci`, `npm test`, установка Chromium, `npm run build`, `npm run test:browser`, GitHub Pages и `npm run test:public` для конкретного SHA.
- Доступные через подключение Skills проверены; четыре затребованных пакета в активном каталоге отсутствуют. Отмечать прямое применение нельзя.
- Открытые задачи по доступности, нагрузке, CSS и независимой визуальной проверке не приравниваются к успешному CI. Их критерием остаётся фактический результат.

## Выявленные риски

1. В `styles.css` присутствуют повторные и частично переопределяющие правила деморежима. Требуется точечное приведение к одной каскадной системе, не допуская регрессий размеров.
2. Сцены 1/2 всё ещё содержат собственные управления общим `t`. Общий store синхронизирует данные, но UX-дублирование не устранено окончательно.
3. До настоящей версии подписей осей числовые тики после pan/zoom были статичны. Внесена динамическая генерация в `src/graphics/svg/gradient.js`, приёмочный тест ещё обязателен.
4. Тестирование Firefox/WebKit, zoom/reflow и поведения ассистивных технологий не сертифицировано как пройденное.
5. Перепроверять GitHub Pages только при известном точном SHA, не полагаясь на успешный push.
